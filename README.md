# Video Kit — монтаж роликов через Claude Code

Набор превращает сырую запись говорящей головы в готовый ролик: вырезает неудачные дубли и паузы,
собирает инфографику, которая появляется на произносимых словах, делает субтитры и сводит звук.
Монтирует Claude Code по инструкциям из набора.

## Установка (один раз)

1. Нажмите зелёную кнопку **Code → Download ZIP** вверху этой страницы.
2. Распакуйте архив туда, где в пути **только латинские буквы**, например `Desktop/video-kit`.
   Нужно 5 ГБ свободного места.
3. Откройте эту папку в Claude Code и отправьте:

   ```
   Установи набор: запусти установщик для моей системы, разбери отчёт и почини, если что-то не встало.
   ```

   Установка занимает 10–20 минут.
4. Дальше — файл `1-START-HERE.txt` в папке набора: как монтировать ролик.

## Обновления

Ничего делать не нужно: раз в сутки Claude сам проверяет новую версию и обновляет набор,
ваши ролики не трогаются. Что нового — в [CHANGELOG.md](CHANGELOG.md).

Если у вас версия 1.0 (без автообновления), один раз напишите Claude в папке набора:

```
Обнови набор с https://github.com/nakomka/video-kit — скачай архив main.zip и замени файлы по инструкции UPDATE.md из архива, не трогай bin, models, cache, projects и kit.json.
```
