# Библиотека компонентов

Это проверенные сцены HyperFrames из готовых роликов. Они уже прошли `hyperframes check`
с нулём находок и рендер. Бери их как основу, а не пиши с нуля.

## Как взять компонент в проект
1. Скопируй файл в `projects/<проект>/project/compositions/<сцена>.html`.
2. Переименуй префикс id во всём файле: `s2-` → `<сцена>-`. Это касается `#s2-root`,
   `data-composition-id="s2"` и `window.__timelines["s2"]`. Три имени должны совпадать
   с хостом в index.html, иначе в рендере будет «Sub-composition timelines not registered».
3. Блок `/*CUES:BEGIN*/…/*CUES:END*/` перезапишет `tools/cues_gen.py`.
   Имена меток (`L("hitTwo")` и т. п.) замени на свои и заведи их в `cues.json`.
4. Цвета берутся из `styles.css` (`--pink`, `--green`, `--panel`, `--ink`). Скопируй его рядом
   и поменяй переменные под палитру ролика. Жёстко вписанные hex внутри SVG и твинов
   (`#ff3d8b`, `#12a35f`) замени вручную.
5. Все сцены рассчитаны на 1080×1920, а верхняя зона `.topzone` начинается со 150px.
   Для 16:9 перепроверь размеры шрифтов и отступы.
