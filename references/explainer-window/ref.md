# explainer-window: говорящая голова в окне снизу, графика сверху
Источник: ref.mp4 · 720×1280 · 30 fps · 46.8 с · −14.2 LUFS · речь: ru

## Раскладка (ответы на 4 стартовых вопроса)
- **Формат:** 9:16 1080×1920.
- **Спикер:** прямоугольное окно со скруглением 36px. Ширина ≈55% кадра, по центру,
  верх окна на ≈63% высоты, тонкая светлая обводка 2px, мягкая тень.
  Окно стоит на месте весь ролик.
- **Главное в кадре:** графика (верхние ~60% кадра).
- **Стиль:** фоны чередуются по сценам: светлый `#f4f2ee` и тёмный `#17181a`.
  На светлом фоне есть тонкий серый «шеврон» у краёв. Акцент оранжевый `#e8622c`,
  текст `#14161a` / `#f4f2ee`. Гротеск (system-ui), подписи моноширинным.
  Карточки белые, скругление 16–20px.
- **Субтитры:** нигде. Весь текст живёт внутри сцен.

## Пайплайн
Полностью по `docs/2-PROMPT-EDIT.txt`: дубли → гейт → рез → cues → сцены → звук.
Музыки в образце почти не слышно; по умолчанию тихая подложка (`--bed -26`) или без музыки.

## Компоненты
| Компонент | Статус | Как сделать |
|---|---|---|
| Окно спикера (прямоугольник снизу) | кодом | вариант `components/layout/speaker-full-to-circle.index.html`: форма rect вместо круга, без перехода |
| Смена светлый/тёмный фон по сценам | кодом | слой `#bg` в index.html, hard cut по `sNIn` |
| Счётчик чисел | есть | `components/scenes/fullscreen-counter.html` (твин объекта `n.v` + `onUpdate`) |
| Карточка GitHub-репо | кодом | панель: иконка, `owner/repo`, описание, ряд метрик; звёзды — счётчик |
| Тосты-ошибки с ✕ | кодом | белая карточка, красный квадрат с ✕, наклон ±3°, pop `back.out` |
| Радиальные волны | кодом | 3 круга `scale 0.6→1.6`, `opacity→0`, со сдвигом |
| Список-степпер | ≈ есть | `components/scenes/checklist.html` + рамка активного пункта (`tl.to` borderColor) |
| Документ со строками + счётчик 800→70 | кодом | цифры в отдельных `span`, перекат `yPercent` |
| Поле ввода с печатью | кодом | посимвольный `textContent` по таймлайну, мигающий курсор |
| Лого Claude | кодом | SVG-звёздочка рисуется вручную или **SVG от человека** |
