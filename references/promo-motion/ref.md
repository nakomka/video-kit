# promo-motion: моушн-промо сервиса «Дубль» (снято телефоном с монитора)
Источник: ref.mp4 · 720×1280 · 30 fps · 33.2 с · −15.7 LUFS · речь: ru только 0–2 с и 9–12 с, остальное музыка

`transcript.srt`: строка 3 («Редактор субтитров…») — галлюцинация whisper, речи там нет.
Реальная речь: «Смотри, что я сделал с помощью Claude Code» и «Этот ролик полностью сделан через Claude Code».

## Раскладка
- **Внешний слой** (съёмка монитора телефоном) не воспроизводится, это живая съёмка.
  Повторяемое — красная плашка-заголовок сверху слева «ClaudeCode — Motion графика. За один промпт.»
- **Промо внутри:** 9:16 1080×1920, спикера почти нет (одна вставка футажа).
- **Главное в кадре:** графика.
- **Стиль:** красный `#e1251b`, крем `#f3efe6`, чёрный `#141414`, фиолетовый хайлайт `#9b7bff`,
  жёлтые/зелёные чипы. Тяжёлый гротеск капсом (типа Druk/Unbounded), плотный трекинг.

## Пайплайн
Графический ролик без реза: шаги 2–3 пропустить (если есть закадровый голос — резать его штатно).
Музыка обязательна: трек человека или `make_music.py`, дроп через `music_fit.py` на энд-кард.
Сцены меняются по битам музыки (`npx hyperframes beats`), а не по словам.

## Компоненты
| Компонент | Статус | Как сделать |
|---|---|---|
| HUD камеры | кодом | отдельная под-композиция на всю длину, номер дубля меняется `tl.set` по началу сцен |
| Кольцо текста | кодом | SVG `<textPath>` по окружности, `rotation` у обёртки |
| Чипы ролей | ≈ есть | `components/scenes/pill-grid-icons.html` |
| Штамп с наклоном | есть | `components/scenes/card-stamp.html` (`#s1-stamp`) |
| Лучи | кодом | conic-gradient или 24 SVG-треугольника, медленное вращение |
| Макет телефона | кодом | рамка со скруглением 60px, «чёлка», `<video>`/`<img>` внутри, `rotationY` |
| Энд-кард | есть | `components/scenes/strike-endcard.html` (`#s9-end`) |
| Зерно/грязь «плёнки» | **скачать** (по желанию) | блок из каталога HyperFrames (`hyperframes-registry`) |

## Нужно от человека
- Лого «Д»/бренда (SVG/PNG), видео говорящей головы для вставки, скрин/превью для телефона.
- Музыка (или синтез).
- Сценарий: тексты сцен, если промо про другой продукт.

## Нужно скачать (с разрешения)
- Тяжёлый гротеск капсом с кириллицей (например, Unbounded / Russo One с Google Fonts).
- По желанию: блоки каталога HyperFrames (зерно, лучи).

## Подводные камни
- Текстов много, а сцены короткие (~3 с): держи на сцене не больше 6–8 слов.
- HUD поверх всех сцен — отдельная дорожка, иначе `timeline_track_too_dense`.
