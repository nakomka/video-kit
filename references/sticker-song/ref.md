# sticker-song: стикер-клип под песню
Источник: ref.mp4 · 576×1024 · 30 fps · 29.3 с · −14.1 LUFS · речь: ru (песня, 8 строк)

## Раскладка
- **Формат:** 9:16 (делать 1080×1920).
- **Спикер:** только голос (песня), в кадре его нет.
- **Главное в кадре:** стикер по центру.
- **Стиль:** розовый фон `#d993b8` с медленно плавающими размытыми светлыми пятнами (боке, появляются со 2-й половины).
  Сверху на ≈20% высоты 2–3 ключевых слова строки: белый рукописный/скруглённый шрифт, лёгкая тень.
  Стикеры — котики в стиле «kawaii» с белой обводкой.

## Пайплайн
Дублей и пауз нет: шаги 2–3 (отбор дублей, рез) **пропустить**, исходная дорожка = «рез».
Словные тайминги снять whisper'ом (`-dtw`) с исходника, затем `cues.json` → сцены.
Звук: без подложки, только нормализация к −14 LUFS (`audio_master.py` без `--music`).

## Компоненты
| Компонент | Статус | Как сделать |
|---|---|---|
| Нарезка стикер-листа | есть | `tools/stickers.py лист.png` → `project/assets/stickers/` |
| Смена стикера по строке | кодом | один `<img>` на строку, pop 0.25 с `back.out(2)`, лёгкое покачивание `rotation ±4` пока висит |
| Подпись-ключ сверху | кодом | 2–3 слова, выход по словам с `y:20→0` |
| Фон с боке | кодом | градиент + 10 размытых кругов, дрейф одним твином на весь ролик (seek-safe) |

## Нужно от человека
- Песня (mp3/wav).
- Стикер-лист или отдельные PNG (котики, перечёркнутый лук).
- Шрифт рукописный с кириллицей (.ttf/.otf) в `assets/fonts/`. Без него будет system-ui.

## Нужно скачать (с разрешения)
- Шрифт, если своего нет (например, бесплатный с Google Fonts). Предложить 2–3 варианта.

## Подводные камни
- Whisper в песне хуже держит тайминги. Проверь метки строк глазами по огибающей.
- Повторы строк 7–8 и 5–6: метки бери с `"n": 2` (второе вхождение слова).
