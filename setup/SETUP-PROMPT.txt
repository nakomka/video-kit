===============================================================================
  ПРОМПТ УСТАНОВКИ. Отправьте это один раз, открыв папку набора в Claude Code.
===============================================================================

WINDOWS — скопируйте и отправьте эту строку:

  Установи набор: запусти setup/setup.ps1, разбери отчёт и почини, если что-то
  не встало. Ничего не переустанавливай сверх необходимого.


macOS — эту:

  Установи набор: запусти setup/setup.command, разбери отчёт и почини, если
  что-то не встало. Ничего не переустанавливай сверх необходимого.


-------------------------------------------------------------------------------
ЧТО ПРОИЗОЙДЁТ
-------------------------------------------------------------------------------

  1. Проверятся Node.js, ffmpeg, Python и numpy; чего нет — поставится
     (Windows через winget, macOS через brew).
  2. Скачается whisper.cpp и модель распознавания речи под ваше железо:
     8 ГБ ОЗУ и больше → большая модель (1.6 ГБ, лучшее качество);
     слабее → модель поменьше, с предупреждением в отчёте.
  3. Поставятся дополнения HyperFrames и прогреется движок рендера.
  4. Запишется kit.json: пути, версии, выбранная модель.

  Занимает 10–20 минут, почти всё время — скачивание.
  Подробный лог: setup\last-run.log

  Повторный запуск ничего не переустанавливает — можно запускать смело,
  если что-то сломалось.


-------------------------------------------------------------------------------
ПОРТАТИВНЫЙ РЕЖИМ (ничего не ставится в систему)
-------------------------------------------------------------------------------

  Если на системном диске мало места, нет прав администратора или набор нужно
  носить на внешнем диске — скажите Claude Code:

    Установи набор в портативном режиме: setup/setup.ps1 -Portable

  Тогда Node, Python и ffmpeg скачаются портативными сборками прямо в папку
  набора (плюс примерно 250 МБ), и в системе не появится ничего.

  Исключение: движок рендера (Chrome, 272 МБ) в любом режиме ложится в
  домашнюю папку, в ~\.cache\hyperframes. Так устроен HyperFrames.
  На macOS в портативном режиме whisper всё равно ставится через brew —
  готовых бинарников под macOS в релизах whisper.cpp нет.


-------------------------------------------------------------------------------
РУЧНЫЕ КЛЮЧИ (обычно не нужны)
-------------------------------------------------------------------------------

  Windows:
    powershell -ExecutionPolicy Bypass -File setup\setup.ps1 -Model large
    powershell -ExecutionPolicy Bypass -File setup\setup.ps1 -Force
    powershell -ExecutionPolicy Bypass -File setup\setup.ps1 -Portable

  macOS:
    MODEL=large bash setup/setup.command
    FORCE=1 bash setup/setup.command
    PORTABLE=1 bash setup/setup.command

  -Model large   принудительно большая модель, даже на слабой машине
  -Force         перекачать whisper и модель заново (если файлы побились)
  -Portable      ничего не ставить в систему
